---
name: Count adjustment baseline
description: Product rule for relative quantity entry in the Veracity count form
---
When staff enter a signed count adjustment, calculate the submitted total from the product's recorded stock.

**Why:** The user confirmed this as the intended baseline when requesting total-count and signed-adjustment entry.

**How to apply:** Keep total-count entry available, and interpret positive or negative adjustment values relative to recorded stock before submitting the resulting total for normal case review.
