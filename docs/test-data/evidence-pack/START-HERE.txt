VERACITY - SYNTHETIC EVIDENCE UPLOAD PACK
All records are fictional. The PNG is an illustration, NOT a real damage photo.

TWO DIFFERENT FILE TYPES
upload-documents/: PDFs and PNG for the case's Case documents section.
csv-records/: structured records for Account > Connected records import.
Do not upload CSVs as case documents, or PDFs in the CSV importer.

BEFORE YOU START
Use a clean demo environment, or an existing compatible product B.
These CSVs use the app's original sample IDs A/B/C, TX010 and DR004.
If already imported, do not import them again. Duplicate IDs can be rejected.
Do not delete teammates' data to reset the demo. If B already has an open
case, use that case only if its quantities match this walkthrough.
If B has already been corrected, this example requires a fresh demo dataset.
Use a count submitted after 20 October 2026, 08:30 MYT so the movements
occur before the count and are eligible for assessment.

1. LOAD STRUCTURED DATA
As Manager, open Account > Connected records.
Import csv-records/products.csv as Inventory products (unless already loaded).
Import csv-records/movements.csv as Unposted stock movements (unless loaded).
Do NOT import additional-evidence.csv yet.

2. CREATE AN INCOMPLETE CASE
Submit a count for Snack Biscuits B: recorded 40, counted 33.
Expected: shortage 7; eligible sale TX010 is -3.
Explained: 3. Unexplained: 4. Normal approval is blocked.
An existing conflicting or additional movement can change these results.

3. UPLOAD SUPPORTING DOCUMENTS
Open the latest version of the open case as Manager or its Staff creator.
In Case documents, choose and upload each file in upload-documents/.
Suggested descriptions:
- Sales summary for existing movement TX010; do not duplicate the record.
- Unverified damage report DR004 claiming four damaged units.
- Synthetic illustration supporting the DR004 demo; not photographic proof.
Expected: all files appear with uploader/time and open correctly.
Refresh: files remain visible.
Explained stays 3, unexplained stays 4, recorded stock stays 40.
Uploading alone does not extract document contents or reconcile quantities.
Review the documents manually. New uploads require refreshing a previously
opened decision view; do not approve from a stale view.

4. OPTIONAL: ADD THE MATCHING STRUCTURED DAMAGE RECORD
After human review, as Manager import additional-evidence.csv as
Unposted stock movements. This imports DR004 for product B, quantity -4.
This is a separate explicit demo step, NOT AI reading the damage PDF.
Return to the latest case and choose Refresh evidence & reassess.
Expected: a NEW assessment accounts for -3 sales plus -4 damage = -7.
Explained: 7. Unexplained: 0. The old assessment stays unchanged.
Stock is still 40 until a manager separately approves the correction.
Under the current rules, numerical reconciliation is not proof of root cause.

5. OPTIONAL: MANAGER DECISION
After reviewing the current assessment and attachments, approve once.
Expected: recorded stock becomes 33; Decision Passport is saved.
A repeated approval must not change stock again.
Documents remain available to authorized readers on the closed case/Passport.
Closed cases, historical views, and Owner views do not allow new uploads.
